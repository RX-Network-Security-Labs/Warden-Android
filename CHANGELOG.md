## [1.0.0] - 2026-06-28

### Initial Release

- Real-time monitoring of Camera, Microphone, Location, Contacts, SMS & Call Log, Storage, Calendar, and Activity Recognition
- Smart Good / Bad / Unknown detection based on app foreground state at exact moment of access
- Shizuku-powered AppOps integration — no root required
- UsageStats API for precise timestamp accuracy
- Duplicate prevention and noise filtering
- Per-app full permission history
- Log export in TXT, CSV, and JSON formats
- Dark and Light theme support
- 100% offline — no internet permission
- Local storage via Room database
- Low battery impact with 10-second polling interval
